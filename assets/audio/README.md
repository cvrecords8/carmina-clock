# Sufi ringtone assets

Place your licensed or royalty-free tracks here. The app expects these filenames (MP3 required; OGG optional for Firefox):

| File | Suggested character |
|------|---------------------|
| `ney-dawn.mp3` / `.ogg` | Solo ney, slow breath, no drums |
| `rubab-twilight.mp3` / `.ogg` | Rubab or setar, rubato, low dynamics |
| `dhikr-whisper.mp3` / `.ogg` | Soft vocal dhikr or hum under pad |
| `santoor-mist.mp3` / `.ogg` | Sparse santoor, long reverb tail |

**Selection tips:** 60–90 BPM, no sudden transients, 2–4 minute loops edited so the seam is inaudible (crossfade 500–1500 ms in a DAW). Normalize to roughly −14 LUFS for gentle wake volume.

**Formats:** MP3 (128–192 kbps) for broad support; add OGG Vorbis as `<source>` fallback. Keep each file under ~3 MB when possible.

To add a ringtone, drop files here and register the entry in `js/tracks.js`.
